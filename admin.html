Setup

Connect the shop to Supabase

  1. In the shop's Supabase account, create a new project (region close to Morocco, e.g. Frankfurt or Paris).
  2. Open SQL Editor, paste the whole content of supabase/schema.sql and press Run.
  3. Still in SQL Editor, run (with the admin's e-mail):
    insert into public.admins (email) values ('admin@your-shop.ma');
  4. Authentication → Users → Add user: create that same e-mail with a strong password (tick “Auto confirm”).
  5. Authentication → Sign In / Providers: turn off “Allow new users to sign up”.
  6. Project Settings → API: copy the Project URL and the anon public key into config.js.
  7. Reload this page, sign in, and press Import starter catalogue.
